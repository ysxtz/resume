### 解析 G:\Project\goodwe\iot（设备边缘侧，补全管道上游）
- iot/ 是**边缘采集端，Rust 实现**（SEBU Edge 系列），与云端 Java 互补，构成完整管道"设备→云"。
- 模块：sebu-edge-collector（主采集，子 crate：modbus/iec104/interface）、sebu-edge-common（通用库：structs/MQTT消息/时间/HTTP/日志，feature 按需开启）、sebu-edge-data-manager（Rust+actix-web+SQLite/PG，本地时序库 ts_data 按天分库 + 无锁实时缓存 DashMap/scc，HTTP API /realtime_data_batch /sync_sql /latest_data）、sebu-edge-formula（公式计算引擎，rust_decimal 高精度，支持 @/$变量、mergeRegister/getBits/bitScale/SQRT 等，把裸寄存器换算成物理量）、sebu-edge-initializer（初始化）。
- 数据流（代码核实）：采集器 Producer 定时(100ms)克隆 Modbus 请求模板 → Consumer 调用 RtuCollector/TcpCollector 读寄存器 → formula 换算 → Vec<TsData>{timestamp,sn,key,value} → GlobalDataHandler 批量 HTTP POST 到 data-manager /realtime_data_batch → data-manager 写本地 SQLite ts_data(按天 tsdb_YYYYMMDD.db) + 实时缓存；配置/控制/调试走 actix-web HTTP。
